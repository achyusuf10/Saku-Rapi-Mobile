# Prompt 10 — Settings, Theme, Language, Entry Point

Patuh penuh pada semua dokumen SakuRapi.

## Task
Implementasikan Settings module.

## Scope
- profile section
- theme switch / selection sesuai fondasi
- language selection bila PRD mengizinkan
- transaction entry point preference bila ada di PRD
- logout action
- reusable settings tile components

## Yang harus kamu lakukan
1. Implementasikan settings screen modular.
2. Simpan preference lokal yang memang perlu disimpan.
3. Hubungkan ke localization/theme foundation yang sudah ada.
4. Pastikan logout flow aman dan membersihkan state yang perlu.

## Output
Berikan:
1. file dan kode lengkap
2. storage/state strategy
3. test minimum
4. edge case yang dipikirkan
