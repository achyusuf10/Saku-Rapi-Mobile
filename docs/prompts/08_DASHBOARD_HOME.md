# Prompt 08 — Dashboard Home

Patuh penuh pada semua dokumen SakuRapi.

## Task
Implementasikan Dashboard/Home SakuRapi.

## Scope
- greeting/profile summary
- total balance summary
- wallet summary cards/list
- recent transactions preview
- Report Perbandingan Bulan/Minggu ini dan bulan/Minggu lalu
- quick action entry points
- period summary ringan sesuai PRD
- empty/loading/error state

## Yang harus kamu lakukan
1. Implementasikan dashboard query dan state.
2. Hormati `exclude_from_total` saat menghitung total dashboard.
3. Tampilkan recent transactions secara efisien.
4. Tampilkan Bar chart antara bulan ini dan bulan lalu, dan bisa diganti ke mode minggu
5. Gunakan Apache Echarts, dan pakai widget GraphifyView yang sudah aku siapkan, jadi kamu tinggal isi initial options
6. Bikin UI/UX yang simpel, elegan, modern dan futuristik. Campurkan gardient2 pada widget yang diperlukan seperti total balance.
7. Pastikan format uang dan tanggal sesuai locale/timezone app.
8. Jangan pindahkan logic query/agregasi ke widget.

## Output
Berikan:
1. data yang ditarik dashboard
2. file yang dibuat/diubah
3. kode lengkap
4. optimasi/query notes
5. test minimum
